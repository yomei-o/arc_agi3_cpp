# 物理・化学・数学からの定式化（2026-10-14、4観点のエージェント検討のまとめ）

背景: 順方向MLPは合成分子holdout(dqry)で0.73、天然物holdout(cqry)で0.39、timsTOF天然物(tqry)で0.35。
学習した「割れ方の癖」が化学クラスをまたいで移らない。分子の種類によらない法則で補えないか。

## 4人の共通結論
1. **まず切り分け（E0/E1）**: 0.39の原因は「フラグメント列挙が足りない（転位・RDA・糖）」のか「強度予測のずれ」なのか「組成式の取り違え」なのか。
   - E0: 真の組成式で候補を絞ったoracle MRR − 現状 = 組成式推定で取れる上限。
   - E1: 真の構造で、観測強度のうち質量で説明できる割合（任意の部分組成式 / 1〜2結合切断列挙）。差が小さければ列挙拡張は無意味。
   - uniform強度モデル（全フラグメント等強度）とMLPの比較 → 天然物で同点ならMLPの強度は情報ゼロ。
2. **cosineをやめて正規化尤度に**（全員）。説明できないピークに明示的な罰、断片の多い候補が偶然勝つ偏りを除く。
3. 期待値は各自 +0.02〜0.08（推定）。0.39→0.7には戻らない。天然物の現実的上限 MRR 0.5〜0.6。

## 数学（確率・情報理論）
組成式スコア = 尤度比。元素ペナルティの代わりにOccam因子 1/N_F(M) が自然に出る:

    LR_i(F) = (1−π_i) + π_i · [1/N_F(M_i)] · Σ_{f∈S_M(F)} φ(m_i − m_f; σ_i) / q(d_i | M_i)
    log P(F|D) = log P(F) + log N(m_prec − m_F; σ_p) + Σ_i log LR_i(F)

- N_F(M) = 整数質量Mの部分組成式の数、q(d|M) = 実在フラグメントの質量欠損分布（trainから推定）、π_i = logistic(α+β log強度)。
- 一意に説明（N=1）なら +3.5 nat、C30H46O10 の M=300（N≈30〜40）ならほぼ0 → 大きい式の偶然説明が自動で罰される。
- 検証性質: 帰無の下で E[LR]=1（デコイで確認できる）。
- P(F) は「±10ppm内のプールに実在する式」で十分（P(F) ∝ その式の候補数）。
- 構造: P(s|D) ∝ P(s)·LR_form·LR_iso、条件付きロジット softmax_s(Σ β_j z_j) を天然物holdoutで5〜7パラメータ推定。
- 情報量: 一様な曖昧集合nのMRR = H_n/n。0.39 ≈ 区別できない候補6.5個（残り約2.7 bit）。

## 物理化学（衝突誘起解離）
- チャネル競合 = Boltzmann softmax: b_{n→i} = softmax_i(lnA_i − βE_i + βΔPA_i)、β=1/k_B T_eff。
  loose TS（単純開裂 lnA≈35）vs tight TS（転位・RDA lnA≈26）→ 低CEで転位、高CEで単純開裂（エントロピー・エネルギー交差）。
- 電荷保持（Cooks kinetic method）: ln(I[XH+]/I[YH+]) = (PA_X − PA_Y)/k_B T_eff。PAは官能基加成表で。**異性体区別に最も効く項と予想**。
- 有効温度の自由度依存: eV指定機器で k_B(T_eff−T_0) ∝ CE·N^{−4/3}。天然物は大きく「冷たい」→ 合成分子で学んだMLPは開裂を過大予測しているはず。
- 逐次開裂はフラグメントDAG上のDP（CFM-IDと同構造、logitを物理形に縛る）。パラメータ約20、識別的に（同式候補内の条件付き尤度）推定。
- 検証できる予測: 相補ペアの強度比とΔPAの相関、前駆体残存率のDOFコラプス。

## グラフ理論
- 断片 = 連結誘導部分グラフ、開裂 = 極小辺カット（|C|≤2で環開裂/RDA、XORラベル法で線形時間列挙）。
- 深さ≤3のDAG、結合クラス別コスト、π_G(f) ∝ exp(−κ(f)/τ) で正規化した生成モデル → S(G) = Σ w_p log[P(p|G)/P_0(p)]。
- 原理的な天井: 到達断片の（式,コスト）多重集合が同じ2グラフは区別不能（芳香環o/m/p異性など）→ 事前分布に任せるしかない。
- 典型天然物で節点10³〜10⁴、1候補1〜10ms（Kaggle予算内）。

### 回路の類推（ユーザー提案: 化学も回路も同じ電磁気）
- 対応: ダイオード I=I₀exp(qV/kT) ↔ アレニウス k=A·exp(−E/kT)、差動対の電流分配 I₁/I₂=exp(ΔV/V_T) ↔ Cooks kinetic method I_X/I_Y=exp(ΔPA/kT)、キルヒホッフ電流則 ↔ 断片DAGの流量保存、(G)⁻¹ ↔ 基本行列 (I−Q)⁻¹。今の物理モデルは「結合=ダイオード、断片=節点、イオン流=電流」の回路網と数学的に同一。
- **電圧降下モデル（phys_dag、vLambda/vC）**: 節点ごとに消費エネルギー累計 U（流量加重平均、spend=softplus(E+vC)）を持ち exp(−λU) で減速、E2·depth を置換。深さ2・fqryでフィット → A（E2あり、λ自由）: λは0のまま、cqry 0.420 / tqry 0.379（基準 0.423 / 0.374）。B（E2→0、λ=0.5）: λ動かず 0.418 / 0.371。**改善なし（負の結果）**。深さ2では一定消費と障壁比例の消費が区別できず、spendがEと強く相関するため。深さ3以上で再検討の余地。

## スペクトルの経験則の探索（2026-10-14 夕方、train の [M+H]+ 2万本）

## 仮説: トンネル効果（ユーザー提案、2026-10-14 夕方、未検証）
- トンネル確率 ∝ exp(−2a√(2mV)/ħ) → 重原子の結合開裂では無視でき、**水素移動（McLafferty転位、プロトン移動、物理モデルの H移動 k=±1,±2）でのみ効く**。
- 交差温度 T_c = ħω_b/(2πk_B) ≈ 340 K（虚振動数 1500 cm⁻¹）。CID の有効温度は数百〜千数百K → 主役ではなく補正。Wigner κ ≈ 1 + (ħω/k_BT)²/24: 1000 K で約1.2倍、500 K で約1.8倍。冷たいイオンほど H移動を伴う道筋が古典予想より強くなる（アレニウス-ガモフ、ユーザーの「考える波」第64回と同じ構造）。
- 検証案: (1) H移動の幾何（1,2- vs 1,5-移動＝6員環遷移状態）で重みを分ける特徴を物理モデルに追加し、データが1,5-移動を選ぶか。(2) 分子サイズ（大きいほど冷たい）とH移動重みの関係。(3) 重水素化合物の同位体効果（train にはほぼ無い見込み）。
- **陽子移動（mobile proton）として定式化する案**: [M+H]+ で動くのは主に陽子。最初は最も塩基性の高い部位にあり、励起で分子内を移動し、隣接結合を弱めて開裂させる。今日の電荷保持項（PA で陽子は固定）が効かなかったのはこの前提のせいかもしれない（QCxMS: 最低エネルギーのプロトマーが最良一致なのは51%）。モデル: 陽子の位置分布 p ∝ (I − αA)^{−1} softmax(β·PA)（グラフ上の離散拡散、αが移動しやすさ＝トンネルで増える）、各結合の切れやすさを隣接原子の p で重み付け。電荷保持項をこれで置き換えて検証する。
- **陽子移動の IIR 定式化（ユーザー提案: 決定論ではなく、過去数個の値で次が決まる IIR のような過程）**:
  - 陽子1個の軌跡は確率的、各原子の滞在確率ベクトル p_t は線形差分式で決定的に進む。
  - 1次（マルコフ）: p_{t+1} = W p_t（W = グラフ上の遷移行列、塩基性 exp(β·PA) と移りやすさで決まる）。
  - 高次（記憶あり、振動エネルギーの非平衡で直前の部位に戻りやすい）: p_{t+1} = a₁ W p_t + a₂ W² p_{t−1} + … → 2極で減衰振動＝2つの塩基性部位間のシャトリング（トンネル分裂があればその振動数）。
  - 開裂への結合: C_b = Σ_t γ^t (c_b·p_t) = c_b·P(z)|_{z=1/γ}、P(z) = (I − a₁z⁻¹W − a₂z⁻²W²)⁻¹ p₀ → 時間ステップ不要、数十原子の連立方程式を1回解くだけ（吸収マルコフ連鎖 (I−Q)⁻¹ と同じ数学）。
  - パラメータ a₁, a₂, γ, β（4個程度）。物理モデルの電荷保持項をこの「陽子滞在確率で重み付けした切れやすさ」に置換し、1次（a₂=0）と2次を比べて陽子移動の記憶の有無をデータで検証する。

## 仮説: ブロック（部品）モデル＝粗視化（ユーザー提案: タンパク質はアミノ酸の連結、他の物質も2分子・3分子モデルにできないか、2026-10-14 夕方）

- モデル: 分子を「ブロック=頂点、切れやすいつなぎ目=辺」のグラフに粗視化 → 主な断片 = ブロックグラフの連結部分集合（ペプチドの b/y = 連続部分配列と同じ）。ブロック内部の割れ方は別段で扱う2段モデル。
- 期待: (1) 同一組成式の異性体をブロック構成（糖の数・アグリコン）で区別、(2) ペプチド de novo シーケンシングと同様にスペクトルのはしご（162/146/132…）からブロック列を読む、(3) 読んだブロックの組立てで候補生成（アナログからの生成の体系化）。限界: 単一の縮環骨格（ステロイド母核、小アルカロイド）は分割不可→原子レベルの物理モデルが担当。
- 最初の検証: 天然物のうち切れやすいつなぎ目で2ブロック以上に分かれる割合、その分子でブロック単位の断片が説明する強度の割合。
