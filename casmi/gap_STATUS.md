# 公開上位パイプラインとの差の分析（gap_STATUS）

2026-10-19。分析だけで、ノートブックの実行・フォーク・提出、コードのコピーはしていない。
読んだもの: 上位の公開ノートブック 24 本（ビルド機 `C:\prog\casmi\pubnb2\<name>`、`-m` 付きで取得）、添付データセットの README / LICENSE / MANIFEST（小さいファイルだけ、`C:\prog\casmi\dssmall\`）。
LB の数値は各ノートブックの版メモ・markdown に書かれた作者の申告値（公開 LB は約 130 分子、1 分子で ±0.004〜0.008 動く）。

## 0. 結論（先に）

- **上位の公開ノートブックは、ほぼ全部が同じ 1 本の系統の派生**。部品はどれも同じ ahmedberatozer / prvsiyan / megayak のデータセットで、版どうしの違いはしきい値・候補 DB の差し替え・後段の小さな処理だけ。
  E006（canqiang）→ v7c / E2R2 → rel150 → N1A → CC-BY ChEBI → PubChemLite → pop015、と進んできた。
- 0.354（FPNet＋LightGBM のエンジン 1 本、私たちの v24 0.322 とほぼ同等）から約 0.455 まで、約 +0.10 の上積みは次の 5 つから来ている。
  1. **独立した第 2 エンジン＋逆数順位融合（RRF）**: 約 +0.02
  2. **順方向シミュレータ（ICEBERG / GLACIER）による同一組成式内の並べ替え**: 約 +0.03
  3. **知名度の事前分布をプール内の並べ替えに使う＋PubChem チャネルのゲート・昇格**: 約 +0.03〜0.04
  4. **公式メトリクスと同じ同一性での重複除去と末尾の補充**: 約 +0.01
  5. **候補 DB の追加（ChEBI/LMSD 98k、PubChemLite 386k）を第 2 エンジンに**: 約 +0.01
- **PubChem 全体を「得点で本体に差し込む」方式は、上位側でも失敗している**（「engine-1 のランカーに PubChem 候補を入れる」−0.018、「融合の後で PubChem の昇格を強制する」−0.031）。上位側で効いたのは、(a) プール内での知名度による並べ替え、(b) PubChem を別チャネルにして、FPNet の差（rel）で確信がある時だけ 1 位に昇格させ、その後に第 2 エンジンとの融合で拒否できる仕組み。(c) PubChemLite / ChEBI は「文書化・生物学的に関係がある」ことで選ばれた小さな集合で、窓あたりのおとりがほとんど増えない。

## 4. なぜ「PubChem 全体＋知名度」が私たちでは効かず、PubChemLite / ChEBI は上位側で効くのか

1. **窓の大きさとおとりの数**: PubChem の窓は中央値 12,800 件、プールは 107 件（dmitriigluzdov の VISIBLE_WINDOW_COVERAGE）。PubChemLite（386k）や ChEBI/LMSD（98k）を足しても、窓は 107 件から 1.5 倍程度にしかならない。しかもこれらは「アノテーションがある / 生物学的に関係がある」ことで選ばれた集合なので、収録されていること自体が二値の知名度になっている。PubChem 全体を入れると、おとりが約 100 倍になる。
2. **上位側でも、PubChem を本体に得点で混ぜると負ける**（engine-1 ランカーに入れて −0.018、融合の後で強制して −0.031）。上位側の PubChem は、ゲート付きの固定スロット＋確信がある時だけの昇格で、その後に独立エンジンとの融合が拒否役になる。私たちの v25 はスコアで差し込み、拒否役（第 2 エンジン）がない。
3. **確信の量の違い**: 上位側の昇格条件は「FPNet で PubChem 側がプール側より明らかに良い（rel>150）」。私たちのゲートは libSim と bias だけだった。窓の中で正解を見つける力も、私たちの REV2 だけでは窓内 MRR 0.05（pcslot_STATUS）。私たちの 1 段目は `rev + 20·pop`、つまり知名度が主役だった。
4. **知名度の重みの大きさ**: 上位側の PubChem の知名度は 0.25（0.15 にしたらさらに上がった）、プール内は 0.15。どれも z 化した本体スコアに対する小さな補正。私たちの 1 段目の 20·pop は、偏った holdout（tqry 知名度 7.65、enveda-np-examples 9.3、train 無作為 1.9）に合わせた値で、本番では有名な分子ばかりを選んでいた可能性が高い。dmitriigluzdov の NP パネル（有名な分子）でも、知名度で top1 が 40%→93% になるが、LB では +0.004 だけ。**私たちの holdout と同じ偏りが、上位側の内部ベンチにもある**。
5. **プール内の知名度は効いている（+0.010）**: 正解がプールにある分子でも、同じ組成式の異性体を分けるのに使える。私たちはまだ試していない（#1）。

→ 次の手（安い順）:
- #6 重複除去
- #1 プール内の知名度＋PubChem の知名度の重みを下げる
- #2 組成式群の中だけの順方向モデル
- #3 2 本のリストの RRF
- #4 昇格の方式

#5 は #3 と合わせて入れる。評価は holdout2（ha/hb/hc、知名度を合わせたもの）で行い、LB で方向を確認する。
