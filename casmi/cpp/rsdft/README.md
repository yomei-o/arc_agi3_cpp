# rsdft — 実空間格子（差分法）の第一原理計算、自作 C++

シュレーディンガー方程式を格子上の差分方程式にして解く。∇² = 7点ステンシル（空間方向の FIR）、
基底状態は虚時間反復 ψ ← (1 − τH)ψ（励起成分が幾何級数的に減衰 = IIR の低域通過と同じ仕組み）。

## 結果（2026-10-15、ビルド機 w64devkit g++ -O3 -fopenmp）
- `h_atom.cpp` 水素原子: h 0.4/0.3/0.2/0.15 で E = −0.48236/−0.48957/−0.49515/−0.49721（誤差 ∝ h²）、
  2点外挿 −0.49987（正解 −0.5、差 0.08 kcal/mol）。⟨r⟩ 1.5065（正解 1.5）。
  最初の版は n が奇数のとき原子核が格子点に乗り −1/r = ∞ → NaN（n を偶数に固定して修正）。
- `h2plus.cpp` H₂⁺ のポテンシャル曲線（h 0.2、箱 20 bohr）: 谷は R ≈ 2、
  結合エネルギー = E_H(同じ格子) − min E = −0.4951 − (−0.5979) = 0.1028 Hartree（正解 0.1026）→ 格子誤差は差で打ち消す。
  谷の底がガタつく（R 1.8 < 2.0 > 2.2）= エッグボックス効果（原子核と格子点の位置関係が R で変わる）。

## 次
1. エッグボックス対策: −1/r をセル平均、またはなめらかな擬ポテンシャル（GTH 型）に。
2. 速さ: 共役勾配 / Davidson、マルチグリッド前処理、4次ステンシル、CUDA。
3. 2電子（H₂, He）: Hartree 項をポアソン方程式（同じ差分）で、交換相関は LDA。
4. 小分子（H₂O, CH₄）→ 小さなプロトン化分子の結合スキャンで xTB の障壁を較正。
