## 結論（先に）
- **プール済み5分割CV（分子でまとめる、6 holdout）で、クラス混合 a=0.5・装置特徴なしのモデルは手の融合を6セットすべてで上回るか同等**:
  cqry +0.019 / cqry正解除去 +0.014 / **tqry +0.055** / tqry正解除去 +0.047 / sqry ±0.000 / oqry +0.013（同点平均、出力CSV経路と一致を確認済み）。
- ラベル置換の対照はすべてほぼ0（0.01〜0.11）→ 学習経路に答えの漏れはない。
- **見つけた漏れ2つ**（どちらも除去済み）:
  1. sqry/oqry のクエリスペクトルそのものが REV2（rev2_vh.bin、xlib学習）の学習データに入っていた。rev 単独 MRR sqry 0.571 / oqry 0.543（cqry 0.278）。クエリスペクトル2705本を除いた xslib で学び直した `rev2_vh_xs.bin` で 0.473 / 0.473。残る差は「同じ分子の別スペクトルを見ている」効果で、本番（train全体で学習）と同じ条件。
  2. **装置（q_instr）特徴が holdout の作りと交絡**: oqry = 全部 Orbitrap かつライブラリに正解、tqry = 全部 timsTOF かつライブラリにない。q_instr ありだと tqry +0.080 / oqry +0.035 に見えるが、外すと +0.055 / +0.013。隠しテストは全部 timsTOF なので「timsTOF = ライブラリにない側」と学んだモデルは危険 → 本番モデルは q_instr を使わない。他のクエリ特徴（質量・極性・アダクト・スペクトル数）も外した版は同程度（tqry +0.056、sqry −0.013）。
- 固定割当（指示どおり: cqry+rm+sqry で学習・oqry で早期停止・tqry で試験、とその逆）は**ほぼ手の融合と同じ**: ライブラリにある側だけの検証で止めると 20〜60本で止まり、手の融合が局所最適。学習内20%で止めると非ライブラリ側は大きく上がるが、ライブラリ側は**別の種類のライブラリ条件（sqry=同装置可 ↔ oqry=別装置のみ）に移すと大きく下がる**（Bi: sqry −0.08〜−0.14）。→ 両方の種類を学習に入れる（プールCV）ことが必要だった。

## 特徴（48、lm_feat.h）
- モデルスコア（phys / mlp / rev 各4）: クエリ内 z、順位（≤50）、順位/件数、z − 最大z
- 融合: hand（手の融合スコアそのもの）、その順位、最大との差、spec3 = z(phys)+0.25z(mlp)+z(rev) とその順位
- ライブラリ本人照合: lib、lib − クエリ最大、lib 順位、クエリ最大 lib、2番目、lib≥0.8 の候補数
- アナログ: ana（variant4 p3）、最大との差、順位、クエリ最大、他の variant（cos p3, mcos p3, mcos-6pk p2/p4, noprec-6pk p3）
- 生成: isGen, isGen·sim³, 2段, log1p(支持), log1p(兄弟), op 事前確率
- merr（候補質量と窓中心の ppm 差）
- クエリ: log(候補数), 生成候補の割合, スペクトル数, 中性質量, 極性, アダクト, 装置（**本番では不使用**）
- 生の phys / rev
- 使わない（holdout の作りの漏れ）: inLib、プールの train フラグ、COCONUT 掲載・メタデータ、構造記述子。lib は「ライブラリにない候補 = 0」なので lib>0 で分岐はできる（ここが学習の主な得点源で、クラス混合で効き方が変わる）。

## 学習器（lmart.cpp）
- ヒストグラム法（特徴ごと ≤255 分位ビン、分岐は実数しきい値で保存）、葉優先成長（15葉、深さ6、葉の最小40行、L2=1）、学習率 0.05、木ごとに特徴80%・クエリ80%を抽出、親−小さい子のヒストグラム差分、6スレッド
- LambdaMART: 正解1件 × 他の候補の対、|ΔNDCG|（metric=mrr で |Δ(1/rank)|）、σ=1、LightGBM 式のクエリ正規化、正解のないクエリは寄与0
- クラス混合: `mix=N:..,R:..,L:..`（グループごとの総重み、正解のないクエリも数える）
- 早期停止: `val=`（別セット）または `valfrac=0.2`（学習クエリの20%、混合重み付き MRR）
- CV: `fold=k/K`（分子名のハッシュでまとめる＝同じ分子は全セットで同じ fold）、`oof=` で OOF 順位
- 対照: `permute=1`（学習ラベルをクエリ内でランダム化、検証・試験は真のラベル）
- 速度: 1本 約0.035 s（14.5万行×48特徴、4〜6スレッド）。推論は無視できる（500本×候補数）。
