# 量子化学の障壁計算を家で続ける手順

GPU は不要（xTB も、次の段の DFT/PySCF も CPU で動く）。

## 1. 入れるもの
- **xTB 6.7.1**: https://github.com/grimme-lab/xtb/releases から自分の OS 用を取って展開。
  Windows は `xtb-6.7.1-windows-x86_64.zip`、Linux/WSL は `xtb-6.7.1-linux-x86_64.tar.xz`。
- **Python 3.10 以上** と `pip install rdkit numpy`
- リポジトリを `git pull`（このフォルダ `casmi/py/qm/` を使う）

## 2. 場所の指定（環境変数）
```
# Windows (cmd)
set XTB_EXE=C:\path\to\xtb-6.7.1\bin\xtb.exe
set TS_GEO_DIR=C:\path\to\ts_geo
# Linux / WSL
export XTB_EXE=$HOME/xtb-dist/bin/xtb
export TS_GEO_DIR=$HOME/ts_geo
```
`TS_GEO_DIR` には各スキャンの「山の頂上」の構造（*_top.xyz）が保存される（次の段の DFT 一点計算に使う）。

## 3. 動かす
```
cd casmi/py/qm
# 試運転（3分子、6並列、結合の種類ごとに1本）
python ts_scan.py data_ts/fqry_mols.txt 3 ts_smoke.csv 6 1
# 本番（150分子、8並列、種類ごとに3本まで）
python ts_scan.py data_ts/fqry_mols.txt 150 ts_scan150.csv 8 3
# 分析（種類ごとの障壁と、観測された断片との対応）
python ts_analyze.py ts_scan150.csv data_ts/huckel_fqry2.json
```
引数: `ts_scan.py <分子リスト> <分子数> <出力CSV> [並列数] [種類ごとの本数]`。
速さの目安: スキャン1本 = 1コアで数十秒〜数分（ビルド機12並列で 85本 数分）。
CSV は1本ごとに書き足すので、途中で止めても書けた分は残る。

## 4. データ（data_ts/）
- `fqry_mols.txt` — 合わせ込み用の天然物 1000 分子（InChIKey14 <TAB> SMILES）
- `huckel_fqry2.json` — その [M+H]+ スペクトルでの観測ラベル（切断ごとに両側の偶数電子陽イオンが 0.01 Da 以内に出ているか、+0.3 Da の偶然一致対照付き）。huckel_export2.py で作成
- `ts_scan40.csv` — 2026-10-15 の最初の結果（40分子・85本）

## 5. ここまでの結果（2026-10-15）
- 障壁の低い順 **アシル 28 < C–ヘテロ 50 < C–C 85 < アリール–C 108 kcal/mol** = 物理モデルを実測に合わせて得た序列と同じ（昨日の BDE では出なかった）。
- アリール–C/C–C の 85〜108 kcal/mol は CID の内部エネルギー（1〜3 eV = 23〜70 kcal/mol）では越えられない → 実際の断片は **水素移動・転位を伴う低い経路**で出ている。スキャンの約半分は頂上が見えない（plateau）。
- 同じ種類の中で「障壁が低いほど観測される」かは、ラベル付き 39 本では判定不能（AUC 0.42〜0.60）。

## 6. 次にやること
1. 150分子の結果で、同じ種類の中での判定（AUC）を出す。
2. 水素移動を伴う経路: アリール–C は ipso 炭素へのプロトン移動（アレニウムイオン）→ 切断、C–C は H 移動 → 中性分子の脱離。xTB の `--path`（反応物と生成物を与えて最小エネルギー経路）で障壁を出す。
3. 山の頂上の構造で DFT 一点計算（PySCF, ωB97X-D/def2-SVP 程度）をして xTB との差を見る。
4. 障壁を「結合の種類 + 環境（隣接原子、共役、電荷の位置）」の式にまとめ、C++ の物理モデル（phys_size 系）に入れて、作り直した holdout で測る。

## 7. 追記（2026-10-15 18時前）: アリール–C は ipso プロトン化経路で障壁が下がる（`ts_ipso.py`）
- プロトンを置換基の付け根の環炭素（ipso）に移したアレニウムイオンから切ると、**障壁の中央値 108 → 38 kcal/mol、18本中18本で直接切断より低い**（`data_ts/ts_ipso40.csv`）。38 kcal/mol ≈ 1.65 eV は CID の内部エネルギーで越えられる範囲 → アリール–C 断片が観測される理由の説明になる。
- 内訳: プロトン移動のコスト −25〜+37（中央値 +13）、アレニウムからの切断 3〜78。
- 注意: 移動コストが負の例（−25〜−2）が 6 本 → 「基準」の N/O プロトン化が最安定でない（環炭素や別の部位の方が塩基性、または配座が1つだけ）。基準を「全部位のうち最安定」にする必要あり。plateau も 7 本。
- 最初の版は相手炭素の H を1個落とすバグ（SetNoImplicit 後に GetTotalNumHs を読んだ）で 300〜400 kcal/mol の偽の値 → 組成チェックで発見・修正。
- 次: (1) 基準を全プロトン化部位の最安定に、(2) C–C も H 移動経路で、(3) 同じ種類の中で障壁と観測の対応（150分子の結果で）。

## 8. 150分子・600本（2026-10-15、`data_ts/ts_scan150.csv`）
| 種類 | 本数 | 障壁 平均 | 中央値 | plateau | 観測 |
|---|---|---|---|---|---|
| アシル | 72 | 30.1 | 23.4 | 32% | 69% |
| グリコシド | 9 | 38.0 | 29.4 | 22% | 40% |
| C–ヘテロ | 254 | 50.5 | 47.5 | 50% | 54% |
| C–C | 188 | 89.2 | 92.6 | 63% | 40% |
| アリール–C | 77 | 106.3 | 112.2 | 66% | 63% |
- 中央値の順 アシル < グリコシド < C–ヘテロ < C–C < アリール–C。合わせ込みの序列（グリコシド < アシル < …）とはアシルとグリコシドが入れ替わるだけ（グリコシドは 9 本のみ）。
- 同じ種類の中で「障壁が低いほど観測」: C–ヘテロ AUC 0.575（134本）、アリール–C 0.58（46本、直接切断の障壁なので ipso 経路で測り直すべき）、C–C 0.50、アシル 0.40 → **種類の中の差はまだほぼ情報なし**。ラベルが「どちらかの断片が出たか」で粗いこと、断片の大きさ効果と混ざっていること、直接切断以外の経路（ipso、H移動）を見ていないことが原因候補。
- 次: (1) ipso 経路を 77 本全部に、(2) 大きさビンを揃えた上で AUC、(3) C–C の H 移動経路。

## 9. ipso 経路を 150分子のアリール–C 全部に（`ts_ipso_vs_obs.py`、`data_ts/ts_ipso150.csv`）
- 74 本で計算でき、**72/74 で ipso 経路が直接切断より低い**（中央値 111.4 → 38.1 kcal/mol）。
- 観測との対応（ラベル付き 45 本、観測 29）: 直接切断 AUC 0.562 [0.37, 0.75]、**ipso 経路 0.621 [0.44, 0.80]**（切断部分だけでも 0.621）。観測された結合の障壁の中央値 34.4 vs 観測されない 38.4。
- 方向は「ipso 経路の方が観測とよく合う」だが、**45 本では信頼区間が 0.5 をまたぐ → まだ確定ではない**。分子数を 500〜1000 に増やせば判定できる（1本 数十秒、ビルド機14並列で 150分子 約10分）。

## 10. 直接切断の障壁は「種類＋大きさ」を超えない（`ts_size_ctrl.py`、負の結果）
- ラベル付き 319 切断。基準（結合の種類 + 小さい側の大きさビン）AUC 0.698。
- + 障壁（種類内 z）−5.9 mnat/切断、+ 反応エネルギー −4.8、両方 −10.1、**種類内シャッフルの対照 +0.8** → 直接切断の障壁は、種類間の序列以外の情報を持たない。
- 解釈: 実際の断片は直接切断以外の経路（ipso、H移動）で出ている → 経路ごとの障壁で測り直す（アリール–C の ipso は §9、450分子で確認中: `TS_CLASSES=aryl-C TS_SKIP=150 python ts_scan.py fqry_mols.txt 450 ts_aryl450.csv 14 2` → `ts_ipso.py ts_aryl450.csv ts_ipso450.csv 14`）。
- ts_scan.py に環境変数 TS_CLASSES（種類で絞る）と TS_SKIP（先頭 n 分子を飛ばす）を追加。

## 11. 独立な 450分子（アリール–C 180本）での再検証（2026-10-15 18時過ぎ）
- ipso 経路が直接切断より低い: 176/180（150分子と合わせ 248/254）→ **確定**。
- 観測との対応（ラベル付き 112本）、基準を直す前 → 後（`ts_ref.py` = 分子の N/O 全部位で最安定のプロトン化）:
  直接切断 0.598 → **0.647 [0.54, 0.75]**、ipso 経路 0.571 → 0.619 [0.50, 0.74]、ipso の移動部分 0.550 → 0.623。
  → **「ipso の方が観測と合う」は再現せず**（150分子の 0.62 vs 0.56 は45本の偶然）。基準を直すと両方上がる = 効いているのは「切る結合の近くの部位が最安定部位からどれだけ高いか」（エネルギーで測った移動プロトン）。距離で測った近似（approx_test.py）では効かなかった。
- オルト/パラ供与基の法則（156本）: o/p 1個あたり −2.7 ± 1.5、メタ −3.0 ± 2.4 → **o/p だけが効く形は確認できず**。負の移動コスト 15本 = 環炭素プロトン化などを基準で見落とし。
- 次: (1) 基準に環炭素プロトン化と複数配座を入れる、(2) 「部位の相対エネルギー」を全結合種類で特徴にして、種類＋大きさの基準を超えるか（ts_size_ctrl.py 方式）。
